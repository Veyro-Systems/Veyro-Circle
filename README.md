# Veyro Circle

Veyro Circle er Veyro Systems ApS’ (CVR 46834941) webapp til lokal udlejning og deling i Danmark, Sverige og Norge.

Gratisordningen giver permanent op til 5 aktive ting uden betalingskort. Circle Plus er et frivilligt månedsabonnement med op til 20 aktive ting: 29 DKK / 43 SEK / 41 NOK. Eksisterende betalingsaftaler og brugerdata bevares. Se FREEMIUM_VALIDATION.md for validering af ændringen.
