# Veyro Circle

Veyro Circle er Veyro Systems ApS’ (CVR 46834941) webapp til lokal udlejning og deling i Danmark, Sverige og Norge.


Nye konti får op til 5 aktive ting gratis i 180 dage uden kort. Derefter kræves aktiv tilmelding til Circle Plus: op til 20 ting for 29 DKK / 43 SEK / 41 NOK pr. måned. Der oprettes ikke et Stripe-abonnement ved signup, og der sker ingen automatisk opkrævning efter gratisperioden. Brugerdata, historik og eksisterende betalingsaftaler bevares. Se CARD_FREE_180_RESTORATION.md for validering.
